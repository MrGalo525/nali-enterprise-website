NALI STANDALONE WEBSITE
========================

This is a standalone replacement for the uploaded Strikingly editor source.

FILES
-----
index.html   - Main website
style.css    - All website styling
script.js    - Mobile menu, enquiry form and current year
README.txt   - This guide

HOW TO OPEN
-----------
1. Keep index.html, style.css and script.js in the same folder.
2. Double-click index.html.
3. The website will open locally in your browser.
4. It does not require Strikingly, a CDN, an external JavaScript library,
   external fonts, external images or an internet connection.

WHAT WAS REMOVED
----------------
- Strikingly editor code
- Strikingly editor UI/tutorials
- Strikingly tracking/configuration
- External CDN dependencies
- External scripts and styles
- Platform-specific site/editor configuration

IMPORTANT
---------
The uploaded "Nali Website.txt" was primarily a Strikingly editor/source
document and did not contain the actual Nali public-page sections. Therefore
this version recreates the website as a clean section-based Nali site rather
than pretending to reproduce unavailable original page content exactly.

CUSTOMISE
---------
- Replace the text logo with the final Nali logo when available.
- Add your confirmed phone number and email address in the contact section.
- Replace product descriptions/pricing with your final approved wording.
- Add your own product photographs later if desired.

NO EXTERNAL LINKS
-----------------
The generated website contains no http:// or https:// links and no external
website dependencies. Navigation uses local page sections only.

The enquiry form currently works locally and displays a confirmation message.
It intentionally does not send information to a third-party service.
